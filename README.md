# nixos-wisp

NixOS configuration for **wisp** (HP ZBook Ultra G1a laptop), built on
[nixos-core](https://github.com/nullcopy/nixos-core).

- `flake.nix` — consumes [nixos-core](https://github.com/nullcopy/nixos-core)
  as the `core` input; `flake.lock` pins it (update with `nix flake update core`)
- `configuration.nix` — hostname, `core.*` toggles (including `core.fde`
  for FIDO2 LUKS unlock; key management per nixos-core's docs/fde.md),
  user accounts, wisp-specific hardware quirks (fwupd, CoolerControl,
  ForgeBox udev rule)
- `hardware-configuration.nix` — generated by `nixos-generate-config` at install
- `ollama.nix` — ROCm ollama + GTT tuning for the Strix Halo iGPU

## Day to day

```
sudo nixos-rebuild switch --flake ~/.nixos   # or wherever this is cloned
nix flake update core                       # pull in nixos-core improvements
nix flake update                            # bump everything (core + nixpkgs)
```

User environments live in each user's own dotfiles repo (standalone
home-manager); this repo only declares the accounts.

Pre-commit formatting hook: `git config core.hooksPath .githooks` after clone.
